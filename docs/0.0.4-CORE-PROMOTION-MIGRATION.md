# 0.0.4 Core Promotion Migration

NexusEngine `0.0.4` now owns generic MCP infrastructure and renderer-neutral
Object Placement contracts. NexusEngine-Kits removed its candidate
implementations and package subpaths in the same cutover. There are no
forwarding exports.

| Removed Kits import | NexusEngine `0.0.4` replacement |
| --- | --- |
| `@luminarylabs/nexusengine-kits/mcp-domain-kit` | `nexusengine/core-domains/core-mcp-domain` |
| `@luminarylabs/nexusengine-kits/domain-mcp` | `nexusengine/core-domains/core-mcp-domain` |
| `@luminarylabs/nexusengine-kits/mcp/node` | `nexusengine/core-domains/core-mcp-domain/node` |
| `@luminarylabs/nexusengine-kits/object-placement-contract-kit` | `nexusengine/core-domains/core-object-domain/placement` |

Factory replacements:

| Removed factory | Replacement |
| --- | --- |
| `createMcpDomainKit` | `createMcpRegistryKit` |
| `createObjectPlacementContractKit` | `createObjectPlacementKit` |

`defineMcpProvider`, `defineMcpProviderTemplate`, `createMcpSdkServer`,
`connectMcpStdio`, and the placement descriptor and operation functions retain
their names at the replacement subpaths.
