# NexusEngine 0.0.4 Core Cutover

NexusEngine-Kits removed behavior now owned by NexusEngine Core. No package
subpath, factory alias, deprecated Kit, or forwarding export remains.

| Removed external identity | NexusEngine `0.0.4` owner |
| --- | --- |
| `action-input-kit` | `nexusengine/domains/interaction/input` |
| `asset-descriptor-kit` | `nexusengine/domains/asset` |
| `capability-graph-domain-kit` | `nexusengine/domains/composition` |
| `completion-ledger-kit` | `nexusengine/domains/runtime/data` |
| `composition-planning-domain-kit` | `nexusengine/domains/composition` |
| `generic-action-window-kit` | `nexusengine/domains/simulation` |
| `generic-pressure-loop-kit` | `nexusengine/domains/simulation` |
| `generic-resource-loop-kit` | `nexusengine/domains/simulation` |
| `kit-registry-domain-kit` | `nexusengine/domains/composition` |
| `persistence-domain-service-kit` | `nexusengine/domains/runtime/persistence` |
| `persistence-dsk` | `nexusengine/domains/runtime/persistence` |
| `protokit-core` | `nexusengine/domains/composition` plus the owning semantic Domain |
| `spatial-scene-graph-dsk` | `nexusengine/domains/spatial` |
| `spatial-scene-graph-kit` | `nexusengine/domains/spatial` |
| `transform-domain-service-kit` | `nexusengine/domains/spatial` |
| `mcp-domain-kit` and `domain-mcp` | `nexusengine/domains/mcp` |
| `mcp/node` | application-owned transport adapter; no Core runtime forwarding |
| `object-placement-contract-kit` | `nexusengine/domains/object/placement` |

Common factory replacements:

| Removed factory | Replacement |
| --- | --- |
| `createCompletionLedgerKit` | `createDataKit` or `createCompletionService` |
| `createGenericResourceLoopKit` | `createSimulationKit` and `engine.n.simulation.resources` |
| `createKitRegistryDomainKit` | `createCompositionKit` |
| `createCapabilityGraphDomainKit` | `createCapabilityGraphService` |
| `createCompositionPlanningDomainKit` | `createCompositionPlanningService` |
| `createObjectPlacementContractKit` | `createObjectPlacementKit` |
| `createMcpDomainKit` | `createMcpRegistryKit` |

Before:

```js
import { createGenericResourceLoopKit } from "@luminarylabs/nexusengine-kits/generic-resource-loop-kit";
```

After:

```js
import { createSimulationKit } from "nexusengine/domains/simulation";

const engine = createEngine({ kits: [createSimulationKit({ resourceMeters })] });
engine.n.simulation.resources.spend("energy", 1);
```

Historical source and parity notes remain lineage evidence. They are not active
imports or supported runtime compatibility.
