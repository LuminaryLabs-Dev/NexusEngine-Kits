# native-emulator-worker-kit

Import `createNativeEmulatorWorkerKit` through `@luminarylabs/nexusengine-kits/native-emulator-worker-kit`. This optional adapter owns `n:host:extensions:emulator-worker` and provides emulation:worker. See the source API, limitations and shared executable adapter proofs. It is a candidate and is not automatically installable through the trusted registry.
