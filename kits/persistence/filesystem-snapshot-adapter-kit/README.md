# filesystem-snapshot-adapter-kit

Import `createFilesystemSnapshotAdapterKit` through `@luminarylabs/nexusengine-kits/filesystem-snapshot-adapter-kit`. This optional adapter owns `n:runtime:persistence:extensions:filesystem-snapshot` and provides persistence:filesystem-snapshot. See the source API, limitations and shared executable adapter proofs. It is a candidate and is not automatically installable through the trusted registry.
