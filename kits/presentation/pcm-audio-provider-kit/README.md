# pcm-audio-provider-kit

Import `createPcmAudioProviderKit` through `@luminarylabs/nexusengine-kits/pcm-audio-provider-kit`. This optional adapter owns `n:presentation:extensions:pcm-audio` and provides presentation:emulator-pcm. See the source API, limitations and shared executable adapter proofs. It is a candidate and is not automatically installable through the trusted registry.
