# Limits

This is the bounded first Physics/render profile described in `docs/PHYSICS-FIRST-SLICE.md`. Unsupported settings reject explicitly. Full 0.0.5 completion, worker/parallel execution, other native providers and hardware certification are not claimed.

WebGL2 is implemented but could not create a context in this sandbox. Three SVGRenderer was explicitly selected for the measured browser pixel proof. No automatic fallback conceals backend failure.
