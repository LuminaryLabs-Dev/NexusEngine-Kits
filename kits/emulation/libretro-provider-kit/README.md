# libretro-provider-kit

Import `createLibretroProviderKit` through `@luminarylabs/nexusengine-kits/libretro-provider-kit`. This optional adapter owns `n:host:extensions:libretro` and provides emulation:frame-step, emulation:serialize. See the source API, limitations and shared executable adapter proofs. It is a candidate and is not automatically installable through the trusted registry.
