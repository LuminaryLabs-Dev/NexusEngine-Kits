# Migrated Gameplay Kits

Status: official first-party non-Core kits

These atomic kits were removed from NexusEngine's root production surface
because they are optional, platform-specific, or genre-specific. They retain
their original factories through the trusted NexusEngine-Kits registry.

The folder is a source colocation boundary, not one installable mega-kit. Every
factory has its own manifest, registry identity, domain path, and installer
record.
